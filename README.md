# Sistema de Usuários (Python + Tkinter + SQLite)

## 📌 Descrição
Sistema desktop simples de gerenciamento de usuários com interface gráfica. Permite cadastro, login, listagem, busca e exclusão de usuários.

---

## 🚀 Funcionalidades
- Cadastro de usuários
- Login com autenticação
- Listagem de usuários
- Busca por nome ou email
- Exclusão de usuários
- Interface gráfica (Tkinter)

---

## 🛠 Tecnologias usadas
- Python
- Tkinter (GUI)
- SQLite (Banco de dados)
- Hashlib (segurança de senha)

---

## 📁 Estrutura do projeto
- app.py → Interface principal
- auth.py → Regras de autenticação e usuários
- database.py → Banco de dados SQLite

---

## ▶ Como executar
1. Instalar Python 3
2. Executar o arquivo:

```bash
python app.py
